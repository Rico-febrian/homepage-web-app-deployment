# End-to-End CI/CD Deployment: Homepage Form Web Application

Hello welcome to my learning logs! This project demonstrates the successful setup of a **Continuous Integration/Continuous Delivery (CI/CD) pipeline** for a simple Homepage Form web application. It showcases automated deployment practices from code commit to a live production environment.

## 🚀 Key Technologies & Concepts Utilized:
* **CI/CD:** GitHub Actions
* **Containerization:** Docker
* **Cloud Platform:** AWS EC2
* **Networking/Security:** NGINX (Reverse Proxy), Certbot to generate SSL Certificates (for secure public access)
* **Version Control:** Git / GitHub

## ✨ Project Highlights:
* **Automated Workflow:** Configured a robust CI/CD pipeline to automatically build, test, and deploy the web application upon code changes.
* **Secure Deployment:** Implemented essential security measures including reverse proxy (NGINX) and SSL certificates for secure HTTPS access.
* **Scalable Infrastructure:** Deployed the application to an AWS EC2 instance, demonstrating basic cloud infrastructure management.
* **Problem Solved:** Ensures rapid, reliable, and secure deployment of web applications, reducing manual errors and downtime.
